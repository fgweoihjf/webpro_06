# webpro_06

## じゃんけん（ラジオボタン版）

`node app5.js` で起動し，ブラウザで http://localhost:8080/public/janken2.html を開く．

| ファイル | 内容 |
| --- | --- |
| public/janken2.html | 最初の入力フォーム（ラジオボタンでグー・チョキ・パーを選ぶ） |
| views/janken2.ejs | 勝敗の表示と次の入力フォーム |
| app5.js の /janken2 | 手を受け取り，勝敗を判定してテンプレートに渡す |

元の janken.html，janken.ejs，app5.js の /janken は変更していない．

## input要素の type，name，id の働き

- **type**：入力欄の種類を決める．text（文字），number（数字），date（日付），radio（ラジオボタン），checkbox（チェックボックス），submit（送信ボタン），hidden（画面に表示しない値）などがあり，ブラウザでの見た目や入力方法が変わる．
- **name**：サーバに送るときのパラメータ名になる．フォームを送信すると `/janken2?hand=グー&win=0&total=0` のように `name=値` の形でURLに付き，サーバ側では `req.query.hand` のように name で値を取り出す．ラジオボタンは同じ name をつけたものが1つのグループになり，その中から1つだけ選べる．
- **id**：HTML文書の中でその要素を区別するための名前で，同じページの中で重複してはいけない．`<label for="gu">` の for と id を同じにすると，ラベルと入力欄が結びつき，ラベルをクリックしても選択できるようになる．CSSやJavaScriptから要素を指定するときにも使う．id はサーバには送られない．

## htmlファイルとejsファイルの使い分け

- **htmlファイル**（public以下）は，内容が変わらない静的なページに使う．サーバはファイルをそのまま返すだけである．例：最初の入力フォーム janken2.html．
- **ejsファイル**（views以下）は，サーバのプログラムで計算した結果など，アクセスごとに内容が変わる動的なページに使う．`<%= 変数 %>` の部分に `res.render()` で渡した値が埋め込まれ，HTMLが作られてから返される．例：勝敗や勝ち数を表示する janken2.ejs．

一般に，誰がいつ見ても同じ内容なら html，プログラムの結果やユーザの入力によって内容が変わるなら ejs を使う．
